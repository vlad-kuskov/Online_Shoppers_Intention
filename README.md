# Прогнозирование намерения совершить покупку в интернет-магазине

## Описание проекта

В данном проекте исследуется задача **прогнозирования вероятности совершения покупки пользователем интернет-магазина** на основе информации о его поведении во время сессии.

Цель исследования — сравнить различные алгоритмы машинного обучения, оценить их качество, провести подбор гиперпараметров и определить модель, наиболее эффективно решающую задачу бинарной классификации.

В рамках проекта реализованы все основные этапы построения модели машинного обучения:

- исследовательский анализ данных (EDA);
- предобработка данных;
- кодирование категориальных признаков;
- масштабирование признаков;
- анализ дисбаланса классов;
- обучение моделей;
- подбор гиперпараметров;
- оценка качества моделей;
- анализ калибровки вероятностей;
- анализ важности признаков.

# Датасет

В работе используется **Online Shoppers Purchasing Intention Dataset**, опубликованный в репозитории UCI Machine Learning Repository и доступный на Kaggle.

- **Kaggle:** https://www.kaggle.com/datasets/imakash3011/online-shoppers-purchasing-intention-dataset
- **UCI Machine Learning Repository:** https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset

## Описание датасета

Датасет содержит информацию о **12 330 пользовательских сессиях** интернет-магазина, собранных в течение одного года.

Каждая запись соответствует отдельной пользовательской сессии и описывает поведение посетителя на сайте с помощью набора количественных и категориальных признаков.

Целевая переменная показывает, завершилась ли сессия совершением покупки.

## Характеристики датасета

| Параметр | Значение |
|----------|----------|
| Количество объектов | 12 330 |
| Количество признаков | 18 |
| Числовых признаков | 10 |
| Категориальных признаков | 8 |
| Пропущенные значения | отсутствуют |
| Целевая переменная | Revenue |
| Тип задачи | Бинарная классификация |

## Описание признаков

| Признак | Описание |
|----------|----------|
| Administrative | Количество посещённых административных страниц |
| Administrative_Duration | Время, проведённое на административных страницах |
| Informational | Количество информационных страниц |
| Informational_Duration | Время, проведённое на информационных страницах |
| ProductRelated | Количество страниц товаров |
| ProductRelated_Duration | Время просмотра страниц товаров |
| BounceRates | Показатель отказов |
| ExitRates | Показатель выходов со страниц |
| PageValues | Ценность страницы (Page Value) |
| SpecialDay | Близость даты посещения к праздничным дням |
| Month | Месяц посещения сайта |
| OperatingSystems | Операционная система пользователя |
| Browser | Используемый браузер |
| Region | Регион пользователя |
| TrafficType | Источник трафика |
| VisitorType | Тип посетителя (новый или постоянный) |
| Weekend | Признак посещения сайта в выходной день |
| Revenue | **Целевая переменная** — факт совершения покупки |

# Этапы исследования

Проект включает следующие этапы:

1. Загрузка данных.
2. Исследовательский анализ данных (EDA).
3. Предобработка данных.
4. Кодирование категориальных признаков.
5. Масштабирование признаков (`StandardScaler`).
6. Разделение данных на обучающую и тестовую выборки.
7. Стратифицированная кросс-валидация.
8. Подбор гиперпараметров (`GridSearchCV`).
9. Обучение моделей.
10. Оценка качества моделей.
11. Анализ калибровки вероятностей.
12. Анализ важности признаков.

# Используемые модели машинного обучения

В работе исследуются и сравниваются следующие модели:

- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost

Для всех моделей выполняется подбор гиперпараметров с использованием стратифицированной кросс-валидации.
